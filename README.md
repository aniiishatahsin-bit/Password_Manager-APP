# Password_Manager-APP 🔐

A secure and user-friendly Password Manager built with Python.  
This project was developed to help users safely store and manage passwords using strong encryption techniques.

## Features

- Secure password storage using Fernet Encryption
- Simple and intuitive GUI built with Tkinter
- Local encrypted data storage
- Automatic encryption key generation
- Lightweight and easy to use

## Technologies Used

- Python
- Tkinter
- Cryptography (Fernet)
- OS Module
- File Handling

## Security

This application uses Fernet symmetric encryption to protect stored passwords.  
The `secret.key` file acts as the master encryption key required to decrypt saved credentials.

⚠️ Important:  
Keep the `secret.key` file secure and private.
